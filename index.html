Excel + Apps Script Bug Automation

A practical tester-focused automation idea that reduces repeated bug-report work.

QA Bug Report Automation — Demo Developed by Sopan Panchal
WHY I BUILT IT

Reduce repetitive defect-entry work.

I created an Excel test-case sheet using the Excel Extensions feature, with Apps Script running JavaScript logic for the bug-report workflow. The goal is to reduce the time testers spend checking failed test cases and manually creating bug records.

01 Test case status becomes Failed
02 Apps Script detects the failed case
03 Bug record is generated automatically
04 After re-testing, the bug reaches Closed
05 Popup confirms closure and the test case is marked Pass
